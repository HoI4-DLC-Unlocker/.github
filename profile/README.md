# **Automatic Hearts of Iron 4 DLC Unlocker Tool**

**CreamAPI** is an all-in-one tool for unlocking DLC for Hearts of Iron 4. It allows users to unlock all DLC for FREE and AUTOMATICALLY, keeping the DLCs up-to-date automatically, currently working both in Single and Multiplayer versions of the game.

## 🔧 **Troubleshooting**

| Problem                        | Solution                                                                 |
|---------------------------------|--------------------------------------------------------------------------|
| DLCs not showing in-game        | Ensure CreamAPI was run as Administrator and restart Steam.              |
| Game crashes after launch       | Use the “Uninstall” option in CreamAPI and reinstall unlockers.         |
| Missing DLL errors              | Reinstall Koaloader via CreamInstaller’s context menu.                   |
| Still doesn’t work              | Re-run CreamAPI and refresh Steam appinfo for Hearts of Iron 4.    |

## 🧠 **Tips & Notes**

- **Back up your Hearts of Iron 4 folder** before making changes.
- **SteamCMD** will download automatically if missing.
- Works with **official Steam builds only** (no cracked or repack versions).
- If **Hearts of Iron 4** updates, simply rerun **CreamAPI** to reapply the unlockers.
